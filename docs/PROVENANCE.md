## 4. 交付前的图像处理

| 处理 | 说明 |
|---|---|
| 角标裁除 | 裁掉右侧 128 列。生成平台在每张图右下角压印 `AI生成 / WORKBUDDY`，其中 `WORKBUDDY` 为第三方品牌标识，不应出现在可分发的素材中。 |
| AI 标识补打 | **在原角标位置补打一枚不含任何第三方品牌的「AI生成」标识**（半透明深色底 + 白字，右下角）。服务协议 §6.4(i)/(j) 与相关法域附加条款禁止移除、规避或误述 AI 生成标识，故裁除后必须补回等价标识。 |
| 裁切方式 | 左上角对齐的**等比裁剪**，不缩放、不拉伸、不改变纵横比以外的任何内容。 |
| 位置验证 | 用 face-001 的角标作为模板，对全部 15 张原图做归一化互相关匹配，命中位置完全一致（1024×1024 图位于 x=898 / y=954，1024×1536 图位于 x=898 / y=1466），证明裁除右侧 128 列即可完整去除角标。 |
| 格式转换 | PNG → WebP（quality 84, method 6），仅改变编码，不改变画面内容。 |
| 未做处理 | **未**做磨皮、液化、背景替换、锐化或任何美化；未做 AI 修复或补全。 |

原始 PNG 位于 `work/raw/`，属于中间产物，**不随项目分发**。

## 5. 可复核性

任何人都可以按以下步骤复核本文件的结论：

1. 阅读 `docs/GENERATION_QUEUE.json` 中每个任务的 `prompt` 与 `negativePrompt`；
2. 用同样的提示词与参数调用任意文生图模型，比较画面是否一致；
3. 读取 `data/references.json` 中每条素材的 `source.generatedAt`，与文件时间戳比对；
4. 运行 `node scripts/validate.mjs`，确认 id、分类、路径与授权标记的一致性。
