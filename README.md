# 男性 AI 作图参考库（male-ai-reference-library）

成年男性角色的**脸 / 姿势 / 服装**参考素材库。写实风格，中文界面，支持中英文关键词搜索。
纯静态网页，无构建步骤、无 CDN、无外部字体、无后端。

> **当前状态：第一阶段（15 张样图）。** 这是样图版本，**不是完整素材库**。
> 15 张样图分别用于验证三类的构图标准与提示词骨架，尚不足以覆盖真实创作需求。

---

## 运行方法

```bash
cd male-ai-reference-library
python3 -m http.server 8080
```

然后访问 **http://localhost:8080**

> 必须通过 HTTP 服务访问。页面使用 `fetch()` 读取 `data/references.json`，
> 直接双击 `index.html`（`file://` 协议）会被浏览器的同源策略拦截。

## 功能

- **分类切换**：全部 / 脸 / 姿势 / 服装
- **中英文搜索**：一个输入框同时匹配中文标签、英文标签、标题与编号（空格分隔多个关键词为「全部命中」）
- **标签筛选**：按当前分类的标签做筛选，多选为「命中任一」
- **素材详情**：点击卡片查看大图、全部中英标签、生成提示词、负面提示词与授权状态
- **组合台**：脸 / 姿势 / 服装三个槽位，各槽位可**锁定**、**单独换一个**、**清空**
- **随机组合**：一次抽齐三类；锁定的槽位不会被改动
- **复制中文提示词**：一键复制，可直接粘贴到生图模型
- **导出三联参考图 PNG**：带编号与类别标题的三联图板，可下载
- **下载单张素材**
- **响应式**：电脑与手机均可用

### 组合提示词说明

生成的提示词会明确：图 1 用于脸部与发型、图 2 用于身体比例与姿势、图 3 用于服装、
保持同一名成年男性身份、采用所选姿势与服装，并提醒**把导出的参考图与提示词一并提交**
给生图模型。

> 不同生图模型对参考图的理解能力不同，**无法保证人物身份完全一致**。本库不对任何模型作此保证。

## 已知限制

1. **素材仅 15 张**，覆盖的组合十分有限（如无眼镜、无帽子、无手套、无深肤色、无体毛场景、
   无颈部以下发型变化等），不足以支撑真实创作。
2. **图片授权已确认为「可再分发」，但不是公有领域。** 依据服务协议 §9.2(d)，输出归使用者所有；
   底层模型条款、Output 非独家、第三方权利风险等残留项见 [`ASSET_LICENSE.md`](ASSET_LICENSE.md) 第 4 节。
3. **底层模型名称未确认**，`source.model` 留空。复现只能依据提示词与参数，而非精确模型。
4. **图片带有可见的「AI生成」标识**。这是为遵守服务协议中禁止移除 AI 生成标识的要求
   而补打的，不含任何第三方品牌；如不需要可在使用前自行处理，但请自行评估合规性。
5. **服装素材背景不完全统一**：outfit-003 为暖灰色背景，其余为白色。服装**形式**
   （ghost mannequin）是统一的，但背景色存在差异。
6. **组合提示词为固定模板**，不解析用户自由文本；仅描述已选中的参考素材。
7. **姿势与服装类无法表达个体差异**——人偶与 ghost mannequin 形态本身不带面孔信息。
8. **随机组合只使用 `status: ready` 且图片实际可加载的素材**，因此素材变多后组合空间才会明显扩大。
9. **导出图板为静态 PNG**，不含可调参数；面板内的图片按等比 contain 方式留白，不做裁切填充。

## 校验

```bash
node scripts/validate.mjs      # 静态校验
node scripts/browser_test.mjs  # 真实浏览器验收（需先启动本地服务）
```

**静态校验**检查 JSON 可解析、id 唯一、分类合法、必填字段齐全、`ready` 素材图片存在且非空、
图片路径为相对路径、标签在固定词表内、界面未把授权状态显示为比实际更强的承诺、
仓库内无密钥与本机绝对路径。

**浏览器验收**用 Chrome headless + DevTools Protocol 真实驱动页面，逐项检查分类切换、
中英文搜索、标签筛选、锁定后随机不改动槽位、图板导出与三图顺序、详情弹层、
提示词复制、390px 手机宽度横向溢出、控制台报错。共 22 项，当前 **22/22 通过**。
实际结果与「未做的检查」见 [`docs/QA.md`](docs/QA.md)。
